# Assignment 01

**Brief:**  
Starting from the concept of a pinboard, implement a web page that:  
- is responsive (properly layout for smartphone, tablet, and desktop)  
- allows the user to add and remove elements  
- allows the user to customize elements (i.e. colors, size)  
- allows the switch between two views (at least)

**Short project description:**  
I created a pinboard for words and notes that lets users add, organize, and review content in list or card view. Users can customize colors and sizes, highlight items on hover, and easily manage their notes.  

**List of functions:**  
- CHANGE VIEW OF THE CARD  
- COLOR SELECTION  
- SIZE SELECTION  
- ADD CARD  
- DELETE CARD
